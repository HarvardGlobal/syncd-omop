Good to know

Things that will trip you up

Dates

Filter to 2024-01-01 → 2025-12-31. About half of visits (101,757) are older history Synthea carries along, and observation_period starts as early as 1941. All MH/SUD diagnoses fall inside the window.

Scores

Screening scores are in observation.value_as_number, not measurement. If you ever re-run the ETL, run scripts/06b_fix_screening_scores.sql again or the scores will be empty.

Dropped

7,480 dental diagnoses (ICD-10 codes) did not load because ICD-10 wasn't in the Athena download. No MH/SUD data is affected.

Empty

death has 0 rows (only living patients were generated). 288 people have race_concept_id 0 (Synthea race native, hawaiian or other).

Browse

Run scripts/08_view_ares.sh to open OHDSI ARES at localhost:8085: person, condition, drug and data quality reports. 99.16% of 2,384 quality checks pass; the 20 failures are known ETL-Synthea artefacts.

Use

Synthetic data: good for showing the pipeline, cohort logic and feasibility counts. Treatment and timeline rules are assumptions, so don't report treatment effects from it.

Starter query: the four groups (tested, returns 769 / 1,426 / 979 / 6,826)
SELECT CASE WHEN mh AND sud THEN 'both' WHEN mh THEN 'mh_only'
            WHEN sud THEN 'sud_only' ELSE 'neither' END AS grp,
       count(*) AS people
FROM (
  SELECT p.person_id,
         bool_or(c.condition_concept_id IN (4152280, 442077)) AS mh,
         bool_or(c.condition_concept_id IN (433753, 434327, 438130,
                                            432303, 44783367, 4080762)) AS sud
  FROM cdm.person p
  LEFT JOIN cdm.condition_occurrence c USING (person_id)
  GROUP BY p.person_id
) x
GROUP BY 1 ORDER BY 2 DESC;
